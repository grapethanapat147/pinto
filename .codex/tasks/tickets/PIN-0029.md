## Production — needs a decision before PIN-0027 can deploy
The deployed database has neither migration 0006 nor 0007, nor any generated history.
1. **Approved reseed**: `npm run db:remote:seed -- --force`. Simple and exact, but
   destructive: it deletes the granted LINE user, which must be re-granted afterwards with
   `npm run auth:grant-line -- --remote`.
2. **Additive backfill**: a script that inserts history and ad spend without deleting
   anything. Keeps the LINE user; more code to get right.
