### What changed
The Product section said the app "does not yet persist edits" — it has persisted since
milestone 2. It now says what is *actually* still missing, which is any real marketplace
connection, and states plainly that the deployed database is public.

Technical shape called the database "optional" and claimed the app was "concentrated in one
page component". Both were left over from the 748-line prototype this started as.

A new **Traps** section records the four things that have already cost time here: media
queries must stay last in `globals.css`, secrets go in `.dev.vars` and not `.env.local`, the
seed script is destructive, and a LINE user id is scoped to the provider rather than the
channel. Each of those was learned by breaking something.

The design-system notes said "avoid text below 10px". The delivered system asks 13px for Thai
labels and the floor is now 11px, so the guidance was inverted from reality.

"Recommended next development milestones" listed six things that are all done. It is replaced
by what is genuinely left, weighted — with the marketplace adapters first, because that is the
line between a good demo and a product.

Definition of done gains the full check set and the house rule that has earned its place
here: **verify by measurement, not assertion**, and falsify every new test by breaking what it
guards. Several tests in this repo passed against broken code until that was done.
