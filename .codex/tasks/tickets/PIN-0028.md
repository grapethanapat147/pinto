# PIN-0028 — Edit unit cost on the Stock view

**Type:** Feature · **Phase:** 8 · **Status:** Backlog · **Blocked by:** PIN-0026

Spec: `.codex/specs/cost-and-profit.md`, Q4 and Q5.

## Scope
1. An inline cost field per product row on Stock, owner only.
2. A write endpoint that validates, scopes to the session's shop, and persists.
3. Editing a cost changes **future** order lines only — the snapshot means history is not
   rewritten, and that is tested.
4. The Today view's "เพิ่มข้อมูลต้นทุน" button goes to this instead of apologising.

## Acceptance criteria
- [ ] `staff` cannot see the cost column or write to the endpoint — server-side.
- [ ] An unauthenticated write is rejected before touching the database.
- [ ] Changing a cost does not change any existing order line's cost — tested.
- [ ] Invalid input (negative, non-numeric, absurdly large) is refused with a message.
- [ ] `npx tsc --noEmit`, `npm run build`, `npm run lint`, `npm test` pass.
