# PIN-0004 — Apply the migration locally and seed the domain tables

**Type:** Feature · **Phase:** 2 · **Status:** Review

Specs: `.codex/specs/persistence-foundation.md` (D2), `.codex/specs/schema-v1.md`.

## Goal
PIN-0003 generated `drizzle/0000_loud_albert_cleary.sql` but nothing has ever applied it.
Give the local D1 a schema and real rows, so PIN-0006 can build the read path against
something.

## Scope decision — domain tables only
The spec's original PIN-0003 line said "seed from fixtures". Splitting it here:

- **This ticket:** apply the migration locally, seed the **10 domain tables** from
  `app/fixtures/*.ts`.
- **Next ticket:** seed the 7 presentation tables. Those carry the 41 figures currently
  hardcoded in components and are pure data entry — they only matter once the tiles are
  wired, and they would double this ticket for no earlier benefit.

The domain seed is what unblocks the read path; the presentation seed is not.

## Approach
`app/fixtures/*.ts` import only types from `app/types.ts`, so Node 24's native type
stripping loads them directly — the fixtures are literally the seed source (D2), with no
new dependency and no duplicated data.

Local D1 lives in miniflare's persisted sqlite under `.wrangler/state/v3/d1/`. The seed
emits SQL and applies it with `sqlite3`, resolved by glob and failing loudly if the file
is missing or ambiguous. Scripts are named `*:local` so nobody mistakes them for
production tooling — production seeding is out of scope and undecided (spec Q1/Q4).

The conversion helpers **throw rather than guess** — an unmapped channel spelling, a
missing baht amount or an unhandled message stamp fails the seed loudly instead of
quietly writing a wrong row.

### One tsconfig change, and why
Node requires the explicit `.ts` extension for type stripping; `moduleResolution:
bundler` rejects it without `allowImportingTsExtensions`, so `tsc` failed with 6 TS5097s
even though the script ran fine. Enabled the flag (legal here because `noEmit` is on) and
kept the diff to a 4-line insertion — a first attempt reformatted the whole file, which
was reverted.
