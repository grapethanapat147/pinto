# Delivered design system — reference copy

These four files are copied verbatim from `Pinto-New-Design-System.zip`, the second brand
delivery (2026-09-10). They are the **source of truth** for the palette, and
`tests/design-tokens.test.mjs` fails if `app/globals.css` drifts from `design-tokens.css`.

Do not edit them to match the app. If a token must change, change it in a new delivery and
copy that in, so the app and the design system never disagree silently.

The rest of the delivery — the artwork, `design-system.html`, `brand-board.png`,
`dashboard-preview.png`, the font files and the PNG copies — is not checked in. The artwork
that ships lives in `public/pinto/`; the previews are reference material that เกรพ holds.
