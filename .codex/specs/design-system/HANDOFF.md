# นำไปใช้ใน Pinto

1. นำ assets/ ไปไว้ public/pinto/ ในแอป และอ้างอิงไฟล์ตามชื่อ
2. ใช้ logo-lockup.svg ใน sidebar, mascot-full.svg ใน Login/empty state, mascot-bust.svg ในพื้นที่ภาพประกอบ, mascot-head.svg เป็น avatar
3. แทน favicon เดิมด้วย favicon.svg; อัปโหลด line-channel-icon.png ใน LINE Developers Console; ใช้ og-image.png สำหรับภาพแชร์
4. รวม design-tokens.css กับระบบ CSS เดิม เปลี่ยน --green ที่หมายถึงสีส้มเป็น --brand แล้วตรวจทุกจุดอ้างอิงก่อนลบ :root เก่า ไม่แทน globals.css ด้วย tokens.css ทั้งไฟล์
5. แอปที่ใช้ next/font/google อยู่แล้วใช้ Noto Sans Thai เดิม ไม่โหลดฟอนต์ซ้ำ

## สัดส่วนและขนาด
- รักษา aspect ratio และใช้ height: auto เมื่อกำหนดความกว้าง
- Full: แนะนำอย่างน้อย 300px เพื่ออ่านข้อความป้าย; ขนาดเล็กลงใช้ Bust/Head
- Head: 20px ขึ้นไป; favicon มีเวอร์ชันลดรายละเอียดสำหรับ 16–20px
- Logo ไม่มีกรอบ เว้นพื้นที่รอบภาพอย่างน้อยหนึ่งในสี่ของความสูง mark
- Head และ logo ต้องคงโบว์ส้ม; ป้าย Full ต้องไม่ทับใบหน้า มือรองฐานกล่องไม่เริ่มจากกลางผิวกล่อง

## กฎระบบ
- สีตาม brief ทุกค่า; ใช้ส้มประมาณ 4 จุดต่อหน้าจอผลิตภัณฑ์
- UI cards ขาวบน #F5F0EC, ขอบ 1px #EBE4DF, radius 8px, ไม่มีเงา
- ปุ่ม radius 7px; ปุ่มรองเป็นข้อความ; ตัวเลขใหญ่ weight 600; ตัวเลขเปลี่ยนแปลงไม่ใช้ pill
- Base 15px / 1.55, Noto Sans Thai 400/500/600/700; spacing 4/8/12/16/20/24/32
- Lucide 18–21px / stroke 1.9; ปุ่มมีพื้นที่กดอย่างน้อย 44px และ focus ชัดเจน
- สี Soft และสีสถานะบางคู่ไม่ผ่าน contrast สำหรับข้อความเล็ก ให้ใช้ Ink กับข้อมูลสำคัญและใช้คำร่วมกับสี; label ภาษาไทยในตัวอย่าง 13px
- ตรวจแอปจริงที่ 1440 / 1024 / 760 / 390px หลังติดตั้ง

ภาพ mascot มีมิติจากพื้นที่แสง–เงาโค้งและการซ้อนวัตถุ ใช้แสงจากซ้ายบน; ตัว UI ยังไม่มีเงา
ชุดนี้ไม่ได้ติดตั้งเข้า source code ของแอปหรือเชื่อมต่อบัญชีร้านค้าจริง ปุ่มและแท็บในคู่มือเป็นตัวอย่างการใช้งาน
